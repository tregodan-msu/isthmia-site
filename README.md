# Isthmia Archives

The records of the excavations at Isthmia in one place: inventory cards, color slides and other collections, with the Isthmia photographs of the Gregory slide archive and the coins of the Clement catalog. Filter by type, area, trench, date and ruler.

**Site:** <https://tregodan-msu.github.io/isthmia-site/>

8,647 records, brought together from the Isthmia archives listed below.

## Using the site

- **Browse and search:** https://tregodan-msu.github.io/isthmia-site/browse/ (gallery, table, map, charts and a full-screen viewer).
- **About:** [About the archive](https://tregodan-msu.github.io/isthmia-site/), [The Isthmia archives](https://tregodan-msu.github.io/isthmia-site/project/), [Methodology](https://tregodan-msu.github.io/isthmia-site/methodology/), [Takedown policy](https://tregodan-msu.github.io/isthmia-site/takedown-policy/).
- **Collections:** Isthmia Inventory Cards, Isthmia Color Positives. Each is a button in the Type bar above the filters; records from the other Isthmia archives listed below are included too.
- **Permanent links:** every record has one, of the form `https://tregodan-msu.github.io/isthmia-site/#<collection>/<ID>`.
- **Download the data:** the Export menu on the site gives what is shown, or all records, as CSV or JSON. The complete catalogue is also in this repository as [`data/archive.json`](https://tregodan-msu.github.io/isthmia-site/data/archive.json).

## The Isthmia archives

One of a family of connected archives for the excavations at Isthmia:

- [Clement Coin Catalog](https://tregodan-msu.github.io/clementcoins/): Browse and search the coins from the UCLA/OSU/MSU excavations at Isthmia catalogued by Paul A. Clement: obverse and reverse photographs, mints, dates, weights and find contexts.
- [Gregory Archive](https://tregodan-msu.github.io/gregoryarchive/): Browse, search and visualize the Timothy E. Gregory slide archive: 31,000+ photographs of Greece, Byzantium and the Mediterranean.

## About this repository

This repository holds the **published website only**. It is written by an automated build and replaced in full each time the site is published, so changes made here are lost: please do not edit it or open pull requests against it. The catalogue is maintained by the archive team in a separate editor. To report a problem with a record, use the contact above.
