Start a new collection from its photos, or from a table of them. A collection has its own records, fields and editor and is shown inside Isthmia Archives under its own Type; it needs no public repo. Each image becomes one record (ID = file name without the extension); with a table (CSV or Excel, uploaded or from a link) the records also carry its columns and the site is set up from them; without one, titles and other data can be typed in the editor or merged from a CSV later. Creating the site commits its settings to the private repo; the steps after that (AWS, the public repo) are listed once it is made. The full guide is NEW_SITE.md in the repo.

Records from a table (optional)

A CSV or Excel file with one row per image (a column with the image file names; the other columns become the records' fields). Upload it or paste a link: a direct link to a CSV/XLSX, a Dropbox or GitHub link, or a Google Sheet published to the web as CSV. Without a table the site starts with just its photos.
